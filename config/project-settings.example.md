# 项目配置示例

按需要复制为 `config/project-settings.md`。只填当前任务依赖的信息；未知写未配置，不在文件里保存凭据。

## 账号与任务

- 账号定位／目标读者：按本项目填写。
- 当前创作项目目录：例如 `projects/current-note/`，使用项目相对路径。
- 内容目标和表达边界：沿用用户已确认要求。

## 竞品来源

- 本地资料目录：例如 `materials/competitors/`，或写未配置。
- 已授权云端笔记库、账号库：按自己的资源填写，或写未配置。
- 表、视图及字段映射：填写本项目使用的资源，实际使用时核对。
- 工具：可用飞书CLI、连接器或公开链接采集器；只写名称或位置，不写token。

## 视觉素材

- 封面／内页母版：项目相对路径，或写无，使用Skill默认规格。
- Logo与角色：可选；无素材时省略，不生成仿冒Logo。
- 可公开真实截图：逐项写来源、状态和脱敏要求，按本篇方案选用。
- 字体与特殊版式：按用户确认填写。

## 工具与授权

AI环境需要支持读取本地Skill和保存文件。图片制作需要可用的图像或页面渲染工具；云端资料需要使用者自己的授权。采集器需要Node.js，PowerShell为Windows可选入口。密钥和Cookie不写进配置。
