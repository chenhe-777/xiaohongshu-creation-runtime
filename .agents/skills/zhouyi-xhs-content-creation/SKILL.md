# 小红书图文创作运行版

## 业务结构

围绕目标读者与真实材料研究可迁移的内容机制。总控只负责路由，不复制各分支方法：

1. [选题研究](../zhouyi-xhs-topic-research/SKILL.md)：研究附件与标准选题卡。
2. [内容生产](../zhouyi-xhs-content-production/SKILL.md)：阶段 A 将研究结论与真实输入合成一份创作方案，用户一次确认后，阶段 B 生成视觉与平台文案。
3. 独立治理：用户明确维护方法、规则、版本或 Skill 时进入，不属于日常创作。

账号、竞品来源、工具和视觉素材按[项目配置示例](../../../config/project-settings.example.md)配置。有 `config/project-settings.md` 时优先使用；只补影响当前任务的配置，不要求先填完整张表。

## 最小读取与路由

默认只读本文件、[路由与状态协议](references/contracts/01-路由与状态协议.md)、当前状态及本轮有效产物摘要。检查具体交接时再读[标准选题卡](references/contracts/02-标准选题交接卡.md)或[子 Skill 接口](references/contracts/03-子Skill输入输出协议.md)相应一节，不预读多个分支。

识别本轮唯一任务，盘点选题卡、最终选择与真实材料、候选／批准创作方案、实际成品和发布证据；按路由协议选择后，交给该分支继续已授权工作。文件存在不等于批准，多个候选只使用可定位的当前有效版本。

新任务不再加载旧简报 Skill 和旧简报模板，不把完整研究附件、历史项目、Governance、REF 或十三步快照交给创作端。仅有自己的文章、截图和方法，不代表市场与竞品研究完成；研究证据先查项目竞品库及关联原始材料，明确库内缺口后再补证。

## 交接要点

- 创作阶段 A：研究侧可交接的选题卡＋用户确认的最终机会、真实解决办法、当前状态、公开材料及边界；支持独立研究同版卡，保留“用户研究／系统未复核”。
- 创作阶段 B：当前用户明确批准的创作方案与相关素材。旧批准内容方案及继承简报按内容生产兼容规则处理，不重走批准。

交接只传当前有效主产物及必要素材。

## 状态与授权

状态和旧项目迁移只维护在路由协议。用户改变人群、主问题、期望结果、真实方案或主要承诺时，识别受影响下游、保留旧版并标为 `superseded`，从正确上游建立新版本；不把泛泛“继续”当作新方向批准。

不编造事实、研究结论、经历、实跑结果或发布状态；不把单篇表现变成普遍规律。外部写入、发布和正式方法修改按用户授权执行，遇到登录、验证码、频控或重复失败保留缺失并停止当前路线。

方法维护时转 `governance_requested`，核对现有规则及关联文件，展示具体修改、原因和检查方式；用户已明确批准的范围内持续完成，不重复请求批准。

## 精简路由决定卡

```text
下一站：{Skill／模式／当前停止状态}
依据：{一句话原因}
交接：{主产物名@版本；没有则写“新建”}
待补：{仅阻塞推进的1—3项；没有则省略}
```

只请求会改变路由的缺口，不把待补问卷写进完整正式方案。选择分支后执行该分支，不由总控代写内容，也不退回旧十三步运行。
