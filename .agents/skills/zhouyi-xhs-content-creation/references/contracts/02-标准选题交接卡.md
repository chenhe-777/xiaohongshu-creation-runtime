# 标准选题交接卡｜选题拆解与创作启发

## 使用原则

这张卡是“研究侧已经足够交接”的决策件，不是研究过程中的半成品，也不代表已经具备生产条件。详细样本、反向证据、账号基线、投流与偶然性分析留在研究附件；卡片只保留会改变后续创作的结论。用户确认机会及第4部分五项输入后，才进入创作策划准入检查。

研究中仍有未知很正常。判断标准不是把所有未知清零，而是看未知是否会改变“能不能做、选哪个机会、可以承诺什么”：

- 会改变上述决定的未知是**阻塞缺口**，继续研究，不生成本卡；
- 只限制因果归因或承诺强度的未知是**剩余风险**，留在研究附件，并在卡中转成一句明确的“本轮不能据此主张”；
- 不把“作者势能、投流仍未排除”等研究过程用语直接留给用户当待办。

研究 Skill 与用户独立填写使用同一张卡。独立模式只保留一个机会 `O1`，并把研究判断标为 `用户研究／系统未复核`。

## 1｜一眼判断

```text
研究对象：
一句话判断：建议做／收窄后可做＋一句话原因
目标读者与任务场景：
内容目标：流量／搜索／信任／产品／服务／待定
下一步：确认预填内容，补充未知项
```

本区只说明研究什么、服务谁、研究侧是否值得交接以及下一步做什么，不在这里重复痛点、机会或详细推荐理由。输入来源、批次、版本和执行时间写入内部元数据。正式卡只在研究侧可以交接时生成，因此不另设“交接状态”字段。

## 2｜可用于创作的研究结论

```text
需求与场景：谁在什么具体情境下遇到什么损失或阻碍
当前创作空间：需求为何现在仍值得测试，现有内容哪里没有讲清或仍有采用摩擦
可迁移的内容机制：怎样建立相关性、展开痛点、推进理解，并用什么结果或证据建立信任
本轮表达上限：哪些强结论没有被证据支持；这是表达边界，不是待办
研究附件：
```

每项只承担一种信息职责。“当前创作空间”同时消化需求活跃性、周期复现、现有供给缺口和采用摩擦，不把某一个近期数量或搜索信号直接写成因果结论。保留创作结论及少量适用原句或结构，注明来源和改法；省略逐篇研究。

## 3｜推荐机会

研究内部可以比较多个候选方向，正式卡默认只保留综合判断后最值得推进的一个 `O1★`，减少用户审核负担。只有用户明确要求查看备选时才增加 O2/O3；星标表示研究推荐，不替用户做最终选择。

| ID | 创作切口 | 读者看完必须获得什么 | 可承接方向（研究建议） | 采用理由与代价 |
|---|---|---|---|---|
| O1★ |  |  | 产品／Agent／表格／卡片／方法 |  |

机会区只写本轮推荐的具体创作任务，不复制第 2 部分的共同研究结论。若用户明确要求备选，新增方向必须与 O1 在读者任务或兑现内容上实质不同。

## 4｜我的确认与补充

依据已有资料预填五项，未知留空，由用户确认。

```text
最终选择的机会：____
例如：O1

我们准备怎样解决这个问题：
____

目前已经做到哪一步：
____
例如：已经实跑／已有可用版本／正在测试／目前只有设想

可以提供给创作端的公开材料：
____
例如：产品截图、操作过程、真实案例、表格、Agent 运行记录、完成态画面

需要提前说明的条件，以及不能对外承诺的话：
____
例如：只有成员已授权提供周报时才能运行；不能写成无人参与、零遗漏或一键完成
```

用户确认或纠正全卡，只补充未知项。

## 研究过程中的交互

研究 Skill 每轮只返回三种状态之一：

1. `需要补证`：未知会改变选题或机会选择；不给正式卡，只列最多三项补证及用途；
2. `研究侧可交接`：证据足以支持本轮决定；生成本卡，剩余风险已经转成明确表达边界；
3. `不建议推进`：当前证据不支持负责任的机会；不给正式卡，说明停止或改题原因。

补充材料后的版本处理，遵循选题研究 Skill 的“版本与回退”。补证不是越多越好；达到“足以做本轮创作决定”就停止，不追求证明稳定爆款或排除所有现实混杂。

## 独立填写模式

用户已经自行完成市场与竞品研究时：

1. 仍填写本卡四个部分；
2. 第 2 部分写入用户已经得到的跨样本结论；
3. 第 3 部分只保留 `O1`；
4. 研究判断标为 `用户研究／系统未复核`；
5. 第 4 部分同样预填后确认。

## 进入创作策划的最低条件

- 第 1 部分已经给出“建议做／收窄后可做”的明确判断；
- 第 2 部分四项结论彼此独立，并分别回答需求场景、当前创作空间、内容机制和表达上限；
- 至少一个机会及其读者必须获得的内容已经明确；
- 用户已确认第 4 部分五项输入。

缺少阻塞字段时最多请求三项；补齐前不生成完整创作方案。
